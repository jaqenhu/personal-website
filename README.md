# 👾 Jaqen.hu

> 写代码，造 Agent，探索虚拟世界。

Jaqen Hu 的个人作品集，记录 AI Agent、RAG、工作流自动化与数字孪生 / VR 的探索。暗色界面、暖色渐变，让技术和一点个性同屏出现。

🌐 [在线探索](https://jaqenhu-portfolio.vercel.app/)

## `$ cat stack`

`React 19` · `Vite 6` · `CSS` · `Canvas` · `Vercel`

## `$ ls features`

- 粒子星空、角色打字动效与鼠标拖尾。
- 项目卡片和详情弹窗，展示从 AI 到 VR 的实践。
- 核心工具、交付流程与技能进度条。
- 手写 hello、极简联系表单与红色悬停效果。
- 响应式布局，桌面和手机都能逛。

## `$ npm run dev`

```bash
npm ci
npm run dev
```

构建：`npm run build`。内容在 `src/`，图片和字体在 `public/`。
